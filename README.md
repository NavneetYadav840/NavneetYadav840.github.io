# Dr Navneet Yadav: personal CV website

A single-page academic CV site (same design as urru14.github.io), hosted free on GitHub Pages.

## Put it online
1. Sign in to GitHub and create a **public** repository named exactly `navneetyadav840.github.io`.
2. Upload `index.html` (and this README) to the repository.
3. Optional: upload a square headshot named `photo.jpg`. Until then the page shows "NY" initials.
4. Open **Settings → Pages** and check the source is the `main` branch, root folder.
5. The site goes live at `https://navneetyadav840.github.io` within a minute or two.

## Updating
Edit `index.html` on GitHub (pencil icon) and commit; the site refreshes automatically.
Visitors can also print the page (Ctrl/Cmd + P) to get a compact PDF CV.
